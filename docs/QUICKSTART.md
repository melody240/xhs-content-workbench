# 快速开始

## 安装与启动

1. 安装 Node.js 22+、Python 3.11+、Microsoft Edge。Windows 安装 Python 时加入 PATH，安装后重新打开终端。
2. 下载仓库 ZIP 并解压，或使用 README 中的 git clone 命令。
3. 在项目根目录打开终端，执行 `npm run setup`。它只会安装锁定的 Node 依赖、创建项目专用 Python 虚拟环境，并安装 Python 依赖。
4. 执行 `npm start`，保持终端运行，打开 http://127.0.0.1:18180 。按 Ctrl+C 停止源码版服务。

如果系统默认 Python 版本过旧，可设置 `WORKBENCH_SETUP_PYTHON` 为 Python 3.11+ 的完整路径后重新执行 setup。运行期另支持 `WORKBENCH_PYTHON` 指定已有解释器。

## 首次连接 Edge

1. 工作台添加账号，进入「设置 → 连接概览」找到浏览器连接管理及生成的扩展文件夹。
2. Edge 打开 `edge://extensions/`，开启「开发人员模式」，点击「加载解压缩的扩展」，选择该文件夹。
3. 在同一个 Edge 配置中登录小红书及创作服务平台；扫码、验证码由本人完成。返回工作台核实账号。
4. 需要采集 X 或抖音时，点击工作台扩展图标，分别启用对应平台，再完成该平台登录。
5. 进入「设置 → 模型设置」，填写自己的模型接口与密钥，保存并测试连接。

请加载工作台**生成的扩展**，不要加载 vendor 里的原始扩展。连接令牌由本地服务生成，不能拿别人的扩展文件夹直接使用。同一时间只连接一个浏览器配置。

## 正常使用

在内容工作区输入主题，选择最新或最热方向。你选定一个选题后，再由工作台准备正文、标题、话题和相关评论素材。在配图页统一挑图、拖动排序，按需生成语录卡或 3:4 拼图，再核对预览。发布和后续评论会对外写入，请确认当前账号和内容。

官方智能标题需要创作编辑器已完成图文填写并返回候选，工作台采用第一个候选。遇到平台验证、登录失效或候选未出现时按实际错误处理，不保证每个账号都具备此能力。

## 保存位置与更新

源码版：默认 `workbench/data/`；可用 `WORKBENCH_DATA_DIR` 指定其他目录。桌面版：`%APPDATA%\XHSWorkbench\workbench`。配置、密钥、素材与草稿都在本地，更新前自行备份该目录。

源码版更新：停止服务，拉取新代码，执行 `npm run setup`，重新启动。扩展代码变更后在 Edge 重新加载现有扩展。不要将 data 上传到 GitHub。

## 常见问题

| 问题 | 处理 |
| --- | --- |
| 127.0.0.1 拒绝连接 | 在项目根目录执行 npm start，检查终端错误；确认端口 18180 未被另一程序占用 |
| Python 启动失败 | 重跑 npm run setup；检查解释器版本及虚拟环境，避免把 Mac 虚拟环境拷到 Windows |
| 扩展已断开 | 保持服务和 Edge 运行；核对生成目录并重新加载扩展 |
| 页面控件未就绪、截图为空 | 在同一 Edge 检查页面，关闭遮挡弹窗；验证码本人处理，勿连续盲重试 |
| 模型请求失败 | 核对模型名称、接口地址、密钥、额度及服务商状态；保存原文后重试 |
| Linux 无法打开素材文件夹 | 复制设置页显示的文件夹路径，手动在文件管理器中打开 |
