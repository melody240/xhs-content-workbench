# 素材说明

本次公开包含 **359 组作者头像与昵称**，来自维护者现有作者素材池。维护者已明确要求将这些图片和昵称一起上传公开仓库。

- 清单：`workbench/integrations/quote-author-seed/authors.json`。
- 每项只保留 name、handle、file、mime（若有）、sourceURL、sha256。
- 359 个唯一 handle、359 份图片，文件总量 **1,398,966 字节**；无私人账号状态、采集任务或运行令牌。
- 来源链接为对应 X 公开主页。素材文件可通过 sha256 逐一校验。
- 默认背景：`workbench/public/assets/collage-background.jpg`，维护者提供的 3:4 图片。
- X 风格图形片段：`workbench/public/assets/quote-x-chrome.png`，用于原有语录卡模板。

代码的 Apache-2.0 许可证不授予第三方头像、昵称、截图、标志或背景的独立权利，也不表示这些人物认可本项目。素材按原权利状态提供；使用、再分发及对外发布应尊重原权利人和平台规则。涉及素材来源或权利的请求可通过 Issue 联系维护者。

语录卡中的随机互动数只用于创作预览，不是真实统计；随机作者不能被用作真实引言的出处。应使用你拥有授权的身份、头像和文字对外发布。
