小红书内容工作台

第一次使用

  1. 安装并打开程序。在电脑上安装 Microsoft Edge。
  2. 点击菜单「工作台 → 首次设置」，打开 Edge 扩展管理页，开启开发人员模式，选择「加载解压缩的扩展」，选中程序给出的扩展文件夹。
  3. 在同一个 Edge 登录小红书及创作服务平台。验证码与扫码本人处理。回到工作台添加账号并核实连接。
  4. 进入「设置 → 模型设置」，填写自己的模型接口、模型名和密钥，保存并测试连接。
  5. 需要抖音或 X 素材时，点击 Edge 扩展图标，启用对应平台并登录。

做一篇笔记

  1. 输入主题，选择选题方向；挑中一个选题，再准备标题、正文、话题和相关素材。
  2. 在配图页选择图片。点击图片预览，左上角勾选，拖动已选图片排序。需要时生成语录卡或 3:4 拼图。
  3. 核对当前账号、标题正文、图片和发布时间，再预览并发布。结果不确定时先去平台核查，不重复提交。

更新与保存

退出旧程序后，直接运行更高版本的同标识安装器。无需先卸载。资料在 %APPDATA%\XHSWorkbench\workbench，更新前可备份；不要删除该目录。

打不开或连接断开

重新打开工作台，确认端口 18180 未被旧实例占用。Edge 扩展断开时，检查同一浏览器配置并重新加载现有扩展。平台弹窗、验证码和登录由本人处理。菜单「帮助」可打开数据与日志目录，转发日志前先脱敏。
